# Learn help-button Android verification — 1.1.1

The final signed release APK passes **nine native Android 17 acceptance cases**, with zero failures. The new control scenario verifies the visible circled question mark and exact “Click Here to Learn How!” text, semantic accessible-name text, target size and viewport bounds, unclipped content, and a real native tap opening the existing walkthrough. All six Learn categories expose that label. Existing arithmetic/carry/final-answer, random examples, vertical addition, numeric keyboard, rotation, all six Practice configurations, automatic scoring and exact round-time checks pass. The actual native screenshot was visually reviewed and copied to the parent outputs folder.

The APK passes all 18 ZIP CRC checks, signature verification, ZIP alignment, package/version code 10101/version name 1.1.1/minimum API 26/target API 37 checks, and byte-for-byte equality of all three production frontend files. No Android permissions or native ABI libraries were introduced. The existing private release signing key was reused; the signer certificate is unchanged from the prior release.

Build dependencies remain AGP 9.2.1, Gradle 9.4.1, JDK 21.0.13+9 and SDK/Build Tools 37.0.0. Initial cached tool reads under Documents/File Provider blocked or were very slow. The successful regular build used byte-identical Android source, the same cached JDK/Gradle distributions extracted into temporary local staging, an isolated Gradle dependency cache, and the original private signing directory. The full release/test/lint build passed 79 tasks in 45 seconds. A test-only assertion was corrected to follow the accessible name from visible text instead of assuming a redundant aria-label attribute; its five-second rebuild did not alter the release APK hash.

Actual runtime: disposable arm64 Android 17/API37 emulator 5556, WebView 145.0.7632.218. No physical device was modified. The declared minimum API 26 was not separately runtime-tested. Evidence: help-button-android-runtime/android-runtime-results.json, help-button-android-runtime-environment.json, help-button-android-artifacts.json, help-button-android-package-verification.txt, help-button-android-instrumentation.txt and help-button-android-build.txt.

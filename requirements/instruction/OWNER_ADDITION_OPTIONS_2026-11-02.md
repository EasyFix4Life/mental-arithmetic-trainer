# Owner-requested available options — 2026-11-02

The owner requested: “Remove the 1 digit and 3 digit addition options from all application platforms and website platform.”

Applied to both Learn and Practice on Web, macOS, Windows, Android, iPhone and iPad in version 1.1.2. The available combinations are two-digit addition and one-, two- and three-digit multiplication. Addition defaults to two digits, including when switching from a multiplication length that Addition no longer offers.

This supersedes the earlier all-length request only for availability of one-digit and three-digit addition. The supplied original files, general arithmetic algorithms, test fixtures, teaching method, multiplication examples, input handling, scoring and timing remain preserved.
